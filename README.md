## 🌐 Sobre o Projeto

Repositório oficial do meu site pessoal e portfólio hospedado via **GitHub Pages** em **[j0aopfc.github.io](https://j0aopfc.github.io/)**.

O projeto centraliza minha apresentação profissional, formação em **Engenharia de Software (UniCEUB)**, atuação como **Técnico de NOC N1 no Banco de Brasília (BRB Serviços)** e a vitrine dos meus principais projetos acadêmicos e pessoais.

---

## ✨ Características da Interface

- **Layout Full-Screen & Minimalista:** Design limpo e sem bordas desnecessárias no desktop, com total adaptação responsiva para dispositivos móveis.
- **Acessibilidade & Usabilidade:** Estrutura semântica pensada para navegação fluida, leitura confortável e suporte a tema escuro (*Dark Mode*).
- **Deploy Contínuo:** Publicação automática via GitHub Pages a partir da branch principal.
